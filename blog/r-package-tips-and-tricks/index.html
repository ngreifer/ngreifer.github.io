is_null() instead of is.null()

NULL is often used in R code to represent an argument that hasn’t been supplied or that something is absent or not given. We often check for NULL values using is.null(), which returns TRUE when its argument is exactly NULL as FALSE otherwise. Unfortunately, this can miss a lot of important scenarios where something like NULL is supplied, but it’s not exactly NULL; in particular, other length-0 objects, like integer(0L) or list(). To test for these, using identical(length(.), 0L), which I often abbreviate as is_null(). I often accompany it with a function is_not_null(), which is just the negation of is_null().

is_null <- function(x) {
  identical(length(x), 0L)
}

is_not_null <- function(x) {
  !is_null(x)
}

is.null(NULL)
[1] TRUE
is_null(NULL)
[1] TRUE
a <- 1:5
is.null(which(a < 0))
[1] FALSE
is_null(which(a < 0))
[1] TRUE
b <- list(c = "D")
is.null(b[-1])
[1] FALSE
is_null(b[-1])
[1] TRUE

There is rarely a case when I want to check specifically for NULL instead of checking for any length-0 object.

Extracting from ...

The ... function in R allows you not to have to name every argument in your function, which can be good for some lesser used arguments or for keeping your function simple. The basic method to extract information from ... is to create a list object, e.g., args <- list(...). Then you can access the arguments by name, like args$foo. However, a problem with this is that you have to evaluate every argument, even if it is irrelevant (at least for this part of the function). An alternative is to use R’s ...elt() function, which extracts objects from ... by index. But because a user can enter the arguments in any order and instead is likely to name them, it would be nice to extract them by name. Someday R will add this, but for now we can use ...names(), which extracts the names of supplied arguments to ..., and find the position of a given argument name. I put all this into a function called ...get(). Unfortunately, because of how ... works, I also need to pass ... to ...get(). Below is what this function looks like:

...get <- function(x, ...) {
  m <- match(x, ...names(), 0L)

    if (m == 0L) {
        return(NULL)
    }

    ...elt(m)
}

It returns NULL if the named argument isn’t present. Below is how I might use it in a function to save time and memory:

f_slow <- function() {
  Sys.sleep(.25)
}

# Slow version
g1 <- function(...) {
  args <- list(...)

  args$this_arg
}

# Fast version
g2 <- function(...) {
  ...get("this_arg", ...)
}

microbenchmark(g1 = g1(this_arg = 1, f_slow()),
               g2 = g2(this_arg = 1, f_slow()),
               times = 5, check = "equal")
